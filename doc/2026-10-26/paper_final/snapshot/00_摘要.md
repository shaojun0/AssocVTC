## 中文摘要

多模态大模型以稠密的图像块（patch）token 作为视觉接口，token 数随分辨率上升到数百乃至上千；在具身智能等对上下文长度与实时性敏感的应用中，上下文很快被大量低信息量的 token 占满。把图像压缩为固定数量的 token 是常见做法，但压缩预算在训练完成后固定，高精度场景会因此丢失细节。本文提出循环读出压缩（recurrent read-out compression）：编码器在输入序列中拼接 $K$ 个可学习特殊 token，训练时，解码器只能从这 $K$ 个 token 获取图像信息，并要据此重建整幅图像；因此这 $K$ 个 token 合起来必须包含重建所需的全部信息，而不是每个 token 都重复同一份全局信息。压缩是否有效，取决于信息是否保持，而不是 token 数量：压缩后仍能还原布局、物体与边界。解码器以权重共享的 Transformer 块反复读出这些 token：第 1 步的查询为可学习查询基，第 $t$ 步的查询由查询基与上一步输出相加得到，且只读取该步的读窗口；每一步都直接预测整幅图像并接受像素级监督。token 预算由此与读出步数绑定：同一组权重在推理时可截断到任意一步，预算不再在训练时确定，而可以在推理时按场景精度选择。该循环借鉴自适应长度分词的容量递增方式，但作用在读出侧。在 ImageNet-100 上的受控实验表明：在 240M 档（编码器与解码器各约 240 M、合计 481.54 M）下，以 token 数计的压缩率由旧 63M 基准的 3.06 倍（196$\to$64）提高到 6.12 倍（196$\to$32），单步读出达到 32.35 dB，显著高于逐图像块直流基线（18.45 dB）；把同一模型展开到 16 步，PSNR 由 22.07 dB 升到 27.94 dB。与逐块 PCA 的对照按每图连续值个数分层：在 $\le3{,}584$ 个连续值的紧预算端，本文两种瓶颈码（每 token 448 维与 224 维）的 PSNR 均高于同值数 PCA（$+0.89\sim+1.41$ dB）；7{,}168 值处 448 维码仍高 0.34 dB（224 维码仅 L1 更低）；预算放宽到 14{,}336 值及以上时 PCA 反超（$+1.37$ dB；主模型在 39{,}936 值处为 27.94 dB 对 35.75 dB）。把每个特殊 token 由 1248 维压到 448 维（每图连续值降为 36%）只损失 0.25 dB，在同一 14{,}336 值下比旧 63M 基准高 3.54 dB。在公开人评复杂度数据上，图像复杂度与重建误差正相关（5 个容量档 × 3 个子集共 15 个组合全部为正，$\rho=+0.33\sim+0.54$），容量增加缩小的是复杂度惩罚的绝对幅度；容量阶梯在 240M 档达到峰值。总体而言，循环读出压缩以一组固定的 token 配合可截断的读出，在单一模型中提供由少到多的多档 token 预算。

**关键词**：视觉 token 压缩；循环读出；权重共享；特殊 token；深监督；注意力机制

## Abstract

Multimodal large models interface with images through dense patch tokens, whose count grows with resolution to hundreds or even thousands; in applications sensitive to context length and latency, such as embodied agents, the context is quickly exhausted by many low-information tokens. Compressing an image into a fixed number of tokens is common practice, but the budget is frozen once training ends, so high-precision scenes lose detail. We propose recurrent read-out compression: the encoder appends $K$ learnable special tokens to its input sequence; during training, the decoder can obtain image information only from these $K$ tokens and must reconstruct the whole image from them, so the tokens must jointly contain all the information needed for reconstruction rather than each repeating the same global information. Whether the compression is effective depends on whether the information is preserved, not on the token count: layout, objects and boundaries remain recoverable after compression. The decoder repeatedly reads the tokens out with a weight-tied Transformer block: the first-step query is a learnable query base, the query at step $t$ is the query base plus the previous output, and step $t$ reads only its own read-out window; every step predicts the full image and receives pixel-level supervision. The token budget is thereby tied to the number of read-out steps: the same weights can be truncated at any step at inference, so the budget is no longer fixed at training time but can be chosen at inference according to the precision a scene requires. The design borrows the capacity-increasing allocation of adaptive-length tokenization, but the loop acts on the read-out side. Controlled experiments on ImageNet-100 show that at the 240M scale (about 240M parameters each for encoder and decoder, 481.54M in total) token compression is raised from $3.06\times$ (196$\to$64) in the earlier 63M baseline to $6.12\times$ (196$\to$32), and single-step read-out reaches 32.35 dB, far above the per-patch DC baseline (18.45 dB); expanding the same model to sixteen steps raises PSNR from 22.07 dB to 27.94 dB, and Against a per-patch PCA baseline at matched numbers of continuous values the outcome is budget-dependent: at the tight end (up to 3,584 values per image) both of our bottleneck codes (448- and 224-dimensional tokens) are $+0.89$ to $+1.41$ dB above PCA at the same value count; at 7,168 values the 448-dimensional code is still 0.34 dB higher while the 224-dimensional one only wins on L1; from 14,336 values on PCA takes the lead ($+1.37$ dB; at 39,936 values the main model gives 27.94 dB against 35.75 dB), because PCA keeps all 196 spatial positions and only reduces the dimension at each of them, whereas we route the whole image into 32 tokens. Squeezing each token from 1248 to 448 dimensions (36% of the continuous values) costs only 0.25 dB and remains 3.54 dB above the earlier 63M baseline at the same 14,336 values. On public human-rated complexity data, complexity correlates positively with reconstruction error (positive for all 15 capacity$\times$subset combinations, ranging from $+0.33$ to $+0.54$), and increasing capacity shrinks the absolute complexity penalty; the capacity ladder peaks at 240M. Overall, recurrent read-out compression pairs a fixed token set with adaptive read-out, offering a family of token budgets from few to many within a single model.

**Keywords**: visual token compression; recurrent read-out; weight tying; special tokens; deep supervision; attention mechanism
