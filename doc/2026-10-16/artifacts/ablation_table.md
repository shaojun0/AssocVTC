# 消融对比表 — 编码器: 线性注意力 vs 普通 transformer

- 权重: `--enc_attn linear`（昨日）/ `--enc_attn std`（今日, 普通 transformer）
- 解码器 / K / 数据 / 分辨率 / 损失 / 优化器: 两臂**逐项相同**（唯一自变量 = 编码器注意力形式）
- 评测: 全量留出集 5000 张, 四臂**同进程同批次**同口径
- PSNR 口径: **逐图 PSNR 再平均**（与 2026-10-15 报告同口径）
- `L1 (0-255 像素)` 由归一化空间 L1 换算: `l1_norm × 0.226 × 255 = l1_norm × 57.63`（与昨日报告 §3.1 的 8.433 ↔ 0.1463 换算一致）
