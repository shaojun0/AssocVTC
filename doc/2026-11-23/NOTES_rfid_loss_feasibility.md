# 备忘：把 256 tok×12 的 L1 换成 rFID 损失，可行吗？

- 时间：2026-11-23
- 问题：在 `k256x12_t8` 已训练模型（L1 14ep，末步 22.67 dB / rFID 86.50）基础上，**放弃 L1**、改以 batch rFID 为主损失续训，能否把 rFID 压下来？
- 结论：**不能，且比已经失败的"L1 + 小权重 rFID"更差**。不建议跑。下面给证据与机制。

---

## 1. 已有的直接证据：一次干净的单变量 A/B（但不是在 k256×12 上）

`REPORT_k256x12_t8_20261122.md` §3 里的 rFID-loss 阶段**没跑成**（`_init_bottleneck_warm_start`
对已是瓶颈结构的 ckpt 二次 SVD 崩溃，已修）。所以 k256×12 这条配置上**没有任何 rFID 损失实测数字**。
真正的实测来自 `REPORT_rfid_t8_20261120.md` / `REPORT_t8_norfid_20261121.md` 的 zs192@448 单变量对照：

| | 臂 A（control） | 臂 R（rFID λ=1.0） |
|---|---|---|
| 配置 | zs192 @448, K=16, T=8, 3ep/2850 步, 同 s1 初始化 | **仅** `--rfid_weight 1.0` 不同 |
| 损失 | 逐像素 L1（8 步平权） | L1 + 1.0·rFID/2048（**只挂末步**，micro-batch n=16） |
| 末步 PSNR | **21.87** | 18.11（**−3.76 dB**） |
| 末步 rFID | **102.49** | 116.31（**+13.8，它自己的指标也变差了**） |
| 末步 L1_255 | 13.94 | 21.50 |
| 逐步单调性 | 8 步全程单调 | step8 相对 step7 **掉 2.62 dB** |
| 定性 | 仅模糊 | **棋盘格/高频伪影** |
| 时长 | 151.6 min | 166.8 min（+10%） |

训练日志同 step 950：λ=0 recon=0.2626，λ=1.0 recon=0.3994 —— rFID 项在跟重建抢梯度。

**关键**：这个实验里 L1 **还在**，rFID 只是 λ=1.0 的辅助项，而且只在 1/8 步上生效，就已经把模型打崩。
"放弃 L1" 等于把唯一的逐样本锚点也去掉，属于在同一方向上再推一把。

---

## 2. 机制（为什么不只是"权重没调好"）

本仓库 `rfid_loss.py` 用精确 Gram 恒等式算**可微** Fréchet：

```
FID_batch = ‖μx−μy‖² + (‖X‖_F² + ‖Y‖_F² − 2·sum_sv(X Yᵀ)) / (n−1)
```

X, Y 为同 batch 的**中心化** Inception pool3 特征（n×D，D=2048，n=micro-batch）。
三条数学性质决定了小 batch 上它是坏损失：

### (a) 秩-n−1 的零空间：损失看不见 ≥2041 维

`sum_sv(XYᵀ)` 只依赖 X 与 Y 行之间的内积，即只依赖 Y 在这 n 个样本张成的子空间里的投影。
X 中心化后行空间维数 ≤ n−1 ⇒ **对 Y 施加任意满足 `X Δᵀ = 0` 的扰动 Δ（行和也为 0），损失完全不变**；
该零空间维数 ≥ D−(n−1) = **2041**。零空间里唯一还起作用的是 `‖Y‖_F²`（总能量）。
⇒ 模型可以在 2041/2048 的特征方向上随便加东西（只要批均值与总能量不变），
   **5000 张评测时必然被看见**（样本一多张成子空间就填满了），而训练损失看不见。
   棋盘格/高频伪影正是这种"零空间里的自由"的产物。

### (b) 采样偏置是一个**永不消失的缩方差力**

对从各自分布独立采样的 X、Y：

```
E‖μ̂x − μ̂y‖² = ‖μx − μy‖² + tr(Σx)/n₁ + tr(Σy)/n₂
```

右边第二项是纯采样偏置，梯度 ∝ **(1/n)·∂tr(Σ_y)/∂θ** —— 它把**重建特征的方差往 0 推**，
正是真 FID 里 `Tr(Σx+Σy−2(ΣxΣy)^{1/2})` 想要的**相反方向**。n=8 时这股伪力是 n=64 时的 8 倍，
且**不随训练消失**（它不收敛到 0）。目标函数和优化器看到的东西不是同一个东西。

### (c) 没有 L1 = 没有逐样本锚点

FID 只由 (μ, Σ) 构成。当前的解码器是**确定性、一图一码**的：L1/L2 是**唯一**把"这个码"
和"这张输入图"绑定起来的项。去掉它之后：
- 逐图张冠李戴几乎不受惩罚（paired Gram 只剩一点 Procrustes 式对齐压力，且只活在 ≤n−1 维里）；
- 8 步累计解码的结构失去监督 —— 末步可以任意吃掉前面所有步的输出（老实验里末步 PSNR 掉
  2.62 dB、前面 7 步的 PSNR 也被 BPTT 反向污染，从 19.63 掉到 19.41）；
- rate–distortion 曲线失去意义（无法再声称"每一步多 192 values 换来多少 dB"）。

---

## 3. 还有一层：rFID 是**配对**指标，本来就不衡量生成质量

rFID 是 `FID(recon_i, gt_i)`，配对关系已经把"内容对齐"白送了。它剩下的主要是
"糊不糊 / 有没有伪影"，不是"像不像真图"。所以优化它 ≠ 优化审稿人看重的 FID。
ALIT 的 8.25 是**非配对** FID（生成分布 vs 真实分布），两者不可直接对照（见 REPORT §2.3 的诚实边界）。

---

## 4. 这只模型上"主解码器事后接分布级目标"的四次尝试，方向完全一致

| 尝试 | 配置 | 预算 | ΔPSNR | ΔrFID |
|---|---|---|---|---|
| **L2（MSE）** | k256×12，3ep 续训 | 3.8 h | +0.08…+0.31（升） | **+2.6…+4.3（差）** |
| **VGG16 感知 L1**（w=0.15） | k256×12，~2ep | 3.0 h | −0.76 | **+9.03（差）** |
| **PatchGAN hinge**（VQGAN 式自适应 λ） | k256×12，1100 步 | 1.5 h | −1.07 | **+66.5（差）** |
| **batch rFID**（λ=1.0，L1 仍在） | zs192@448，3ep | 2.8 h | −3.76 | **+13.8（差，且连自己的指标都输给 λ=0）** |

四次都是负结果，机制同一：**主解码器在收敛后没有余量同时服务逐样本保真与分布级统计**，
尤其本模型 rate 只有 3072 values/图（22.7 dB 重建），信息本身就很紧。

## 5. 如果一定要跑，最小代价的排法

1. **不建议**：纯 rFID（无 L1）。理由见 §2(c)，且无任何先例支持。
2. **不建议**：λ=0.05–0.1 的 rFID 辅助项。已有 λ=1.0 的先例是负结果，小权重只是"小一点的负结果"。
3. 唯一有学术价值的用法：**作为论文消融补齐 §3 的"未完成"** —— L1 + λ=0.05 rFID，2 ep，
   ~2.5 h 训练 + 8 min 评测，预期负结果，但能把表格补完整。
4. 若真要试"大 batch 版 differentiable FID"（FastFID, arXiv:2009.14075 的原始设定需要 ≥256 样本/统计量）：
   本机 micro 8×4 卡 = 32/步，要靠 8 步梯度累积把统计量做到 256，但那样加权的特征来自 8 个
   不同优化步的模型状态，梯度是错的。**不做。**

## 6. 真正该做的（与 `PLAN_refiner_roadmap_20261122.md` 一致）

不要在主解码器上事后加分布级目标，而是**隔离**它：冻结主干 + 6–10M 小 refiner（图像进/图像出，
同一个 refiner 服务 8 个速率点）+ hinge PatchGAN + VGG 感知 + L1 锚。
上 P1 之前先过 **P0-b 决策门**：拿预训练后处理（SD-Turbo img2img strength 0.15–0.25 / Real-ESRGAN）
在现有 5000 张重建上量一个 rFID 天花板，≤40 才值得投入。
