# P0-c 决策门结果：SD-VAE 的自身重建 FID（决定要不要蒸馏）

- 日期：2026-11-23
- 脚本：`p0c_teacher_fid.py`（口径与 `fast_rfid.py` 逐条一致）
- 数据：IN-100 val **5000 张**，256²，Resize(292,BICUBIC)+CenterCrop(256)+ImageNet Normalize
- 特征：官方 FID InceptionV3 pool3 2048d，resize 299，[0,1]→[-1,1]，uint8 量化的内存版

## 三条结论

1. **决策门大幅通过。** teacher 自身 rFID = **3.44**，远低于 25 的阈值 ⇒ 蒸馏目标极好，
   学生会朝一个"确实存在且同量级 rate 可达"的低 FID 点收敛。若蒸馏 gap 是 3–8 倍，
   我们可望落在 **10–30**。

2. **我们的差距不在 rate，在解码器先验。**
   - 用我们自己的 R-D 曲线外推：3072→4096 values 只能换来约 **+0.1~0.2 dB**
     （ep14 实测 2688→3072 是 +0.09 dB）。而 teacher 比我们高 **+3.26 dB**、rFID 低 **25×**。
   - 一个**通用** LDM VAE（L1+LPIPS+PatchGAN 训的解码器）在 1.33× rate 下就做到 3.44，
     说明"3072 值上 rFID 86.5"不是物理限制，是训练目标/先验缺失。

3. **我们比"纯模糊"还差。** σ=2.0 模糊的 PSNR 24.56 / rFID 27.20 都比我们好；
   同 PSNR 下我们的 rFID 仍高约 3× ⇒ 除了糊，还有**结构性/色彩损伤**（与定性观察的
   "更平滑 + 色彩偏移"一致）。而 σ=1.0 模糊就已经 rFID 9.15 ⇒ **rFID<10 要求几乎不糊**，
   这也解释了为什么"只加 VGG 感知损失"不够。

## 对论文的含义（要提前准备答案）

审稿人一定会问"既然一个现成 VAE 就能做到 3.44，为什么要用你们的 tokenizer？"
答案只能是**架构差异**（单模型 8 个速率点、循环累计解码、R-D 曲线可控），并且必须
证明"把先验搬进我们架构后它仍然保有这个差异"。这正是本次 KD 实验要拿出的证据。
