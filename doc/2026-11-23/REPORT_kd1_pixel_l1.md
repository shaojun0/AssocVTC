| ckpt | step8 PSNR | step1 PSNR | step8 rFID | ΔPSNR | ΔrFID |

## 结论

1. **方向对、量级不对**：+0.12 dB / rFID −3.3%。预登记（`NOTES_kd_vs_alit_code.md` §6）写的是
   "kd1 75–95"，实测 83.63，落在带内 —— 即"这条臂最多只能挪动这么多"。
2. 与机制解释一致：教师自己相对 GT 的 L1 是 **9.31/255**、rFID 3.44；我们相对教师解码图的 L1 是
   **11.5/255**。像素 L1 里"能换成 FID"的那一小部分被低频误差淹没，即使把 KD 项优化到 0，上限也只
   是教师那 3.44 的"可达性"，而实现这个可达性的前提是**有教师的 decoder**（我们没有）。
3. 同时 `L1(x)` 与 `L1(t)` 是两个不同目标点，收敛解落在两者之间 ⇒ 只能小幅移动（实测 0.12 dB）。
   这解释了为什么 `kd` 项在 1100+ 步里保持在 0.036–0.053 无趋势。
4. **不再给这条臂加预算**。要用逐像素监督继续压 FID，只能走 GAN/LPIPS（那是"训 decoder"，不是蒸馏）。
