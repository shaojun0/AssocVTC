# Qwen3.8-27B 视觉 token（IN-100 train 全池化）PCA：谱、σ 维度与健全性

日期：2026-10-30 · 产物目录：`/root/autodl-tmp/qwen_vtc/pca` · 脚本：`tools/qwen_pca_tokens.py --per_position`

## 0. 摘要（TL;DR）

- 样本：IN-100 **训练集** 126,689 张图 × 49 token × 5120 维 = **6.21M 个 token**，全局池化（不分位置）拟合 PCA；PCA 基在**训练集**上拟合（非 oracle）。
- **σ 定义（权威）：1σ/2σ/3σ = 保留累计解释方差 68.27% / 95.45% / 99.73% 对应的主成分数**，即 **r = 20 / 234 / 754**（全部 = 5120）。
- 位置常量（跨图同位置均值的方差）占池化总方差 **4.5%**，位置内残差占 95.5%（混合方差分解，fp64）；池化 PC1–PC4 与位置均值矩阵 top-4 子空间的最大 cos = 0.92, 0.56, 0.29, 0.77；头号主成分 PC1 本质是 token 幅度/离群通道方向（与 token L2 norm 相关 -0.999，top-10 载荷维占 92.4%）。
- 位置中心化（先减每位置均值 μ_p 再池化，secondary）后 r@1σ/2σ/3σ = 21/239/776（主口径 20/234/754，变化 +5%/+2%/+3%）。
- 量化保真：B2（位置中心化+逐通道归一+逐 token int8）rel_rmse = 0.4914%（token PSNR 46.2 dB），fp16 子集 vs 全量 int8 的 σ 阈值 r 差 = +0/-1/-6 个 PC。
- 特征健全性（mean-pooled 5120 维 + 线性探针，train_index 顺序前 50,000 张）：full-val top-1 = **35.8%**（随机 1%）、top-5 = 39.6%；已见 40 类归一 top-1 = 89.4%；训练 1.4 min ⇒ token 提取链路正常。

## 1. 口径与 σ 定义（必须写清）

- token：Qwen3.8-27B **仅图像编码器**，输入 224×224（14×14 patch，2×2 merge）→ **49 个 merged visual token**，每 token 5120 维，按 row-major 合并网格顺序；同图 49 token 按顺序拼成 49×5120。
- PCA：**整个训练集所有 token 混在一起**（不分位置）做全局中心化 PCA，协方差用全部 6.21M token 的样本协方差；特征分解 float64（GPU），`components.npy` 列 = 降序特征向量（PC1 在第 0 列）。
- **「σ」= 高斯累计质量口径**：保留累计解释方差 68.27% / 95.45% / 99.73% 分别对应 1σ/2σ/3σ；r 定义为满足 cumvar(r) ≥ 目标的最小主成分数。`all` = 5120（100%）。
- 透明性参考：另记 90/95/99/99.9% 阈值；两个**备择口径**（非实验口径）：`alt_mean_mult` = 未标准化时 λ_i ≥ k·mean(λ) 的个数（k=1/2/3）；`alt_kaiser` = 逐维标准化相关矩阵 eigenvalue ≥ k 的个数。

- 总方差 trace(Σ) = 2592；top-1 主成分方差占比 **51.74%**；参与率 PR = **3.70**；entropy rank = **26.13**（维数 5120，即有效自由度远小于 5120）。
- **PC1 机制诊断**（采样 2000 train images (98,000 tokens), B2 dequant, global-centred）：PC1 载荷极端稀疏（top-10 维占 92.4%，单维 max|loading| = 0.936），PC1 得分与 token L2 范数几乎完全相关（pearson = -0.999）⇒ **池化 PCA 的头号主成分 = token 幅度/离群通道方向**；PC1 分数中只有 6.9% 是位置均值差贡献。token L2 norm = 78.9 ± 40.0。这解释了 top-1 share 51.7% 与极陡谱，也意味着低 r 截断主要丢的是「内容」维度而不是幅度维。
- top-k 累计方差占比：

| k | 1 | 4 | 16 | 49 | 64 | 128 | 256 | 448 | 512 | 1024 | 2048 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 占比 | 51.74% | 56.54% | 66.15% | 78.34% | 81.46% | 89.51% | 96.19% | 99.15% | 99.40% | 99.85% | 99.99% |

> k=49 对应「每次读 49 token 的线性维度」（Qwen 送进 LLM 的每图 token 数）；448、1024 为参考点（与 AssocVTC 逐位置记忆维度/常见截断宽度对齐，便于跨实验对照）。

## 3. 存储精度与 int8 量化保真度

存储契约：`train_tokens_int8.npy` (N,49,5120) int8 + `train_scale.npy` (N,49) fp16 + `quant_ref.npz`（`mu_p` (49,5120) f32 + `sd` (5120,) f32）；反量化 **x = (q*sc)*sd + mu_p**（B2 口径 = 位置中心化 μ_p + 逐通道归一 sd + 逐 token absmax int8；μ_p/sd 由 val 5,000 张 fp16 token 估计，只影响存储刻度、不改变 token 语义）。

- **首版 v1（纯 per-token absmax int8）不可接受**：rel_rmse = 14.18%（token PSNR 17.0 dB），因 Qwen token 重尾（共享偏置 + 离群维，absmax/rms≈60，v1 下 44.0% 的维被量化成 0），故整集重提 B2。两版差异说明「存储精度对 PCA 谱不是无关紧要的」，尤其影响高累计阈值的 r。
- **B2 实测**（tokens/quant_check.json）：rel_rmse = 0.491%、token PSNR = 46.2 dB、max|Δ| = 1.459（量化误差在解析界内：|Δ| ≤ (0.5·sc + 127·|sc_fp16−sc|)·sd）。
- 反解质量（fp16 子集对照完全同批图）：max|Δ| = 1.459；相对 RMSE = 0.4914%；token PSNR = 46.2 dB；量化噪声方差占比 = 0.009%（同一子集 int8 反量化总方差 / fp16 原始总方差 = 1.0001）。
- 我们的 f32 分块累积协方差 vs f64 独立复算相对误差 = 2.04e-05（远小于量化噪声，谱由数据决定）。
- **量化噪声对阈值 r 的影响（同 5,000 图子集、同采样，仅换 int8↔fp16）**：1σ +0 / 2σ +0 / 3σ +5 个 PC；抽样噪声（子集 vs 全量）则带来 +0 / -1 / -6 个 PC 的差——后者更大，说明**子集 r 的差主要来自抽样**，B2 量化本身不是 r 的不确定性来源。

## 4. 池化 vs 逐位置（49 个合并网格位置各自 5120 维 PCA）

| 口径 | r@1σ | r@2σ | r@3σ |
|---|---|---|---|
| 池化（主口径） | 20 | 234 | 754 |
| 逐位置（49 个中位数） | 17 | 224 | 732 |
| 逐位置（最小/最大） | 13–23 | 171–237 | 634–755 |

- 池化总方差分解（fp64）：位置常量（组间）117.4（**4.53%**）+ 位置内残差 2474（**95.47%**）= 总 2592（恒等式残差 -5.0e-05）。
  与 AssocVTC 报告「位置常量能量 ~67%」**不同量级**（Qwen 视觉塔的跨图同位置常量占 4.5%，说明 Qwen 视觉 token 的跨图同位置共享分量远小于 AssocVTC 的 patch 记忆；本实验的方差主导项是 token 幅度方向（PC1），见 §2。
- 池化 PC1–PC4 与位置均值矩阵 M(49×5120, μ_p−μ̄) 的 top-4 右奇异子空间重叠：max|cos| = 0.920, 0.564, 0.292, 0.773，主角 = 10.9, 29.0, 48.0, 83.9°；位置均值 top-4 子空间被 PC1–4 捕获 54.7%。
- 逐位置 r@2σ 最宽的位置（row-major 下标/r）：4→237, 5→235, 6→235, 27→235, 1→233；最窄：48→214, 38→212, 35→211, 7→208, 0→171。
- 逐位置 1σ 均值方差占比范围 0.991%–2.832%（均匀 = 2.04%）。

## 5. 位置中心化池化 PCA（secondary，先减 μ_p 再池化）

精确恒等：对 x' = x − μ_p 池化 ⇒ mean(x')=0、cov(x') = mean_p cov_p，所以与逐位置协方差合成完全等价（不二次读 token）。总方差 = 2474（占主口径 95.5%），PR = 3.68，entropy rank = 26.44，top-1 占比 51.92%。

| 口径 | r@1σ | r@2σ | r@3σ |
|---|---|---|---|
| 主口径（全局中心化池化） | 20 | 234 | 754 |
| 位置中心化池化 | 21 | 239 | 776 |

解读：位置中心化后三个 σ 维度的 r 平均变化 +3.4%，说明主口径的 r 里只有 小 的部分来自位置/偏置结构，其余是图像内容本身的高维性。

## 6. 特征健全性（线性探针）

mean-pooled（49 token 平均，5120 维）→ 标准化 → 线性分类器（闭式 ridge，等价线性探针）；**primary**：train 按 `train_index.json` 顺序取前 50,000 张；**control**：随机 20,000 张（覆盖 100 类）；val 用 val_tokens_fp16 + val_labels（5,000 张）。

| 指标 | 数值 |
|---|---|
| full-val top-1 | 35.76% |
| full-val top-5 | 39.60% |
| 已见 40 类归一 top-1 | 89.40% |
| **control（随机 20,000 张，100 类）full-val top-1** | **91.14%** |
| control full-val top-5 | 98.82% |
| control 已见类归一 top-1 | 91.14% |
| 随机猜（100 类） | 1.00% |
| 训练用时 | 1.4 min |

注意：train_index 的 entries 按 (class, name) 排序，所以「前 5 万张」只覆盖前 40 个类 ⇒ full-val top-1 理论上限 ~40%，因此**不能**直接拿 full-val top-1 与 60% 的预期比；已见类归一的 top-1 才是 token 质量的正解。

## 结论（5 条）

1. **σ 维度就是「累计解释方差 68.27/95.45/99.73%」对应的 r**：本实验 r = **20 / 234 / 754**（全部 5120）。参与率 PR = 3.70、entropy rank = 26.13、top-1 占比 51.7%，说明有效自由度只有 ~26，远小于 5120 维；谱在 PC≈222 之后基本进入长尾（λ 十等分首/尾 = 1.34e+03 / 2.4e-06）。
2. **方差被「幅度方向」主导、而不是位置常量**：位置常量仅占池化总方差 4.5%（位置内残差 95.5%）；PC1 与位置均值 top 方向的 max|cos| = 0.92，但 PC1 本身是 token 幅度/离群通道方向（与 token L2 norm 相关 -0.999，top-10 载荷维占 92.4%），位置均值差只解释 PC1 分数的 6.9%。
   池化 PC1–PC4 与位置均值子空间：max|cos| = 0.92，位置均值 top-4 子空间被 PC1–4 捕获 54.7%。
3. **位置中心化后 r 没有下降、反而略升 +3.4%（1σ +1、2σ +5、3σ +22 个 PC）**：位置常量只占 4.5% 方差，扣掉它不会降低有效秩；剩下的高维性来自图像内容本身（位置中心化池化总方差为主口径的 95.5%）。
4. **存储精度影响可控**：B2（位置中心化+逐通道归一+逐 token int8）rel_rmse = 0.491%（46.2 dB），同一 5,000 图子集上 int8 vs fp16 的 σ 阈值 r 差仅 +0/+0/+5 个 PC；首版 v1 per-token absmax rel_rmse 14.18% 则明显更差、且会让高阈值 r 虚高，故弃用。
5. **token 提取链路正常**：mean-pooled 5120 维线性探针 primary（train_index 顺序前 5 万张，因 entries 按类排序只覆盖 40 类）：已见类归一 top-1 = 89.4%、top-5 = 99.0%（full-val top-1 = 35.8%，受 40 类上限约束）；control（随机 20,000 张、100 类）：full-val top-1 = 91.1%、top-5 = 98.8%（随机猜 1%）。⇒ token 顺序/归一化/分辨率正确，没有旋转或打乱。

## 7. 与 AssocVTC 240M 逐位置 PCA 的口径差异（不可硬比数值）

- AssocVTC 240M（2026-10-30 报告）：逐位置 PCA，每位置 1248 维（12×13×8 的 patch 记忆），rank@95% = 335，PR = 27.5。
- 本实验：Qwen 视觉塔 224² → 49 merged token × 5120 维，**池化**（所有位置混在一起）PCA；维度、位置数、token 语义都不同，因此 r 的绝对数值不能与 1248 维逐位置结果直接比较，只能对比「有效秩/参与率」相对大小与 σ 维度占比。

## 8. 边界与注意事项

1. **存储精度**：token 以 int8 + fp16 scale + quant_ref 存储（30GB），反量化用 B2 公式 x=(q*sc)*sd+mu_p；B2 rel_rmse 0.49%，首版 v1 per-token absmax 为 14.18%（不可接受，已重提）。PCA 用 B2 反量化值（fp16 子集仅作校验），见 §3。
2. **池化口径**：49 个 token 不区分位置地混在一起算一个协方差；与逐位置（每位置独立 PCA）以及AssocVTC 逐位置 1248 维都不可硬比。位置常量占 4.5%（§4）。
3. 224×224 输入（14×14 patch → 2×2 merge = 49 token × 5120 维），没有多分辨率/多裁剪。
4. **内存/精度口径**：协方差累计按 **4096 图/块**（200704 token/块）在 GPU 上做 f32 块内 XᵀX + f64 跨块累加，并**先减参考中心 c**（第一块均值）避免 mean² 与方差之间的 f32 相消；实测 f32 路径 vs f64 独立复算协方差相对误差 2.04e-05。chunk 必须 ≤4096，否则单块 f32 激活超 32GB 显存（这是踩过的 OOM 坑）。
5. 特征分解用 **GPU float64 eigh**（5120 维 1.2 s，与 numpy float64 复算 eigvals 相对误差 ~1e-7，阈值 r 完全一致）；但 `components.npy` 存 **float32**（探针投影用；逐元素相对误差 <1e-4，按子空间主角比较时受 sqrt(eps) 放大，退化子空间内特征向量本身不唯一）。
6. PCA 基在**训练集**池化 token 上拟合（可泛化口径，非 oracle）；训练集与 val 同域（IN-100）。
7. 逐位置只存**特征值**（阈值 r、方差占比、位置常量分解），没存 49 个逐位置特征向量；位置中心化 PCA 是 secondary，精确等价于 mean_p cov_p，主口径产物未受影响。
8. 谱被少量离群通道/幅度方向主导（PC1 51.7%，top-10 载荷维 92.4%）：PCA 是为方差而非重建优化的基，低 r（1σ=20）截断会丢掉大量内容维度（top-k share k=49 仅 78.3%）——探针的低 r 结果应理解为「方差意义下最重要的 r 维」，不是「重建意义下最优的 r 维」。
9. 特征健全性只用 mean-pool 的线性探针（5 万张训练），不是完整协议精度评估。
